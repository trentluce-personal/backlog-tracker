# Backlog Tracker

A locally hosted personal backlog tracker for organizing todos and projects.

## Status

Planning stage. No application has been implemented yet. The initial scope below
describes planned capabilities, not currently available features. The technology
stack has not been confirmed.

## Proposed initial scope

- Organize tasks into projects.
- Track tasks with a description, priority, optional due date, and status.
- Move tasks through **Backlog**, **In Progress**, and **Done**.
- Search and filter tasks.
- Persist data locally.
- Start with personal use, without accounts or cloud services.

## Setup

Setup and usage instructions will follow implementation. There is currently no
application to install or run.
